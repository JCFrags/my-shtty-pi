# Compatibility

The package manifests are authoritative for Node.js and Pi peer ranges.
The source was reviewed against the Pi extension and package model documented by Pi.

This repository has no generated output. Rebuild each package in a clean environment before
any release. Compatibility with future Pi versions is not guaranteed.

`pi-progressive-tools` declares Node.js `>=22.19.0`, Pi `>=0.83.0 <0.85.0`, and TypeBox `>=1.3.0 <2.0.0` in its manifest. It is package-only and does not claim accepted Pi-core integration.
