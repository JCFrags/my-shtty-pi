# Independent state providers

- [Memory](memory.md): source-linked accepted knowledge, corrections, proposals, and time.
- [Todo, Notes, and Workplan](todo-notes-workplan.md): which tool owns which kind of current state.
- [Persistence and complete transfer](persistence-and-transfer.md): durable anchors, branch resolution, import, and rollover contracts.

These pages describe the implemented Context Kit owners. Selection requires one native writer per provider. The [evidence boundary](../design/evidence-and-roadmap.md) distinguishes these implementations from the previously selected legacy owners.
