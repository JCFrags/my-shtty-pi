# ADR-010: Context budgets and validation

Status: records the implemented guarded composer, not default activation or semantic certification. See the [documentation boundary](../README.md#current-documentation-boundary).

## Context

Compaction must retain the regular Pi summary, restrictions, unresolved work, and a safe raw tail without returning an oversized context. Selected rows can fit an intermediate budget but overflow after wrappers and recovery references are rendered.

## Decision

Use one bounded deterministic composer over a pinned state selection, compatible historical memory, and any explicitly verified bounded delta. Keep the separately produced regular Pi summary. Preserve chronological order within timeline sections. Importance can reduce or omit optional detail, not reorder retained experience.

Use bounded row/input limits and a fixed 30,000-token combined summary-and-tail cap. The charter's section-floor table is not the implemented settings interface. Mandatory propositions are not truncated to make them fit. Packed representations receive coverage only for validated propositions present in the final representation.

Validate again after rendering. The live return requires complete mandatory coverage, safe tool pairing, compatible cuts, unchanged runtime identity, and the hard ceiling. A selected V3 failure cancels compaction. Pure preview degradation does not authorize an incomplete live return or legacy lifetime reconstruction. [Context composition](../context-composer.md) owns the detailed path and limits.

## Alternatives

- Replacing the Pi summary violates the retained-summary invariant.
- Raising the ceiling or silently dropping a condition hides overflow rather than resolving it.
- Checking only pre-render row counts misses wrapper and representation loss.
- Rebuilding old history on failure defeats the bounded architecture.
- More semantic/model workers are deferred by A-0004. The existing regular-summary path adds no new provider.

## Consequences

Safe refusal can prevent compaction or rollover on a source with too much mandatory content. The actual original large-session overflow remains unresolved. Cut/category coverage describes implemented extraction and selection, not proof that every obligation was understood. The current context remains intact on refusal.

## Migration

Select the new path only through its existing explicit configuration/canary checks. Keep prior source and derived stores. Persist a minimal envelope in Pi and detailed artifacts privately. No package version alone enables the engine.

## Reversal path

Disable the selected path or restore the previously validated package through [recovery](../recovery.md). Do not rewrite old compaction records, delete obligations, or infer a provider-call authorization from a preview result.
