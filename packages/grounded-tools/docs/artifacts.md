# Package artifact checks

The artifact checks run `npm pack` in an isolated temporary root. npm runs offline with audit, funding, lifecycle scripts, update notifications, and progress disabled.

Exact release verification accepts a supplied path, lowercase SHA-256, and provenance. It creates a mode-0700 custody directory with `mkdtemp` below the caller root. It uses `lstat`, rejects symlinks and non-regular files, enforces a 16 MiB compressed limit, opens with read-only `O_NOFOLLOW`, and compares initial `lstat` and opened `fstat` identity, type, and size. It reads and hashes only the opened handle, then repeats `fstat` and `lstat` before acceptance. After digest success, it writes those exact bytes once to a new mode-0600 private file with exclusive creation. It reopens and verifies only that private file. Errors do not include the supplied path.

The private copy is parsed by a Node standard-library gzip and strict 512-byte ustar parser. The reviewed format is the narrow POSIX npm form: a gzip header with flags zero, valid DEFLATE CRC and ISIZE checks, `ustar\0` version `00`, no prefix, zero reserved bytes 500 through 511, and only regular-file type flags NUL or `0`. Each normal numeric field has its exact fixed-width npm encoding: the numeric portion has only ASCII-octal digits and one final ASCII space, and the field has one final NUL framing byte. Only uid and gid also permit the reviewed all-NUL zero form. Mode must be `0644`, uid and gid must be `0`, mtime must be decimal `499162500` (octal `3560116604`), and device major and minor must be `0`. Linkname, uname, and gname must be empty. The parser rejects early terminators, NUL-terminated normal numbers, signs, blanks, base-256, non-octal bytes, overflow, unsafe values, links, directories, FIFO, devices, sockets, PAX, GNU extensions, sparse records, malformed checksums, non-NUL string suffixes, unsafe names, controls, bidi and format controls, absolute paths, traversal, duplicates, incomplete payloads, nonzero payload padding, empty archives, concatenated gzip data, and any terminal form other than exactly two final zero blocks. It bounds compressed input at 16 MiB, decompressed tar bytes at 128 MiB, entries at 512, each file at 4 MiB, and total regular-file bytes at 64 MiB. It creates an explicit path, regular type, reviewed metadata, size, and payload-digest manifest and compares the reviewed release set.

Production extraction always creates a new mode-0700 `mkdtemp` directory below the helper root. The separately testable extraction primitive checks a supplied target is empty before recording extraction start and rejects a nonempty target without writing a manifest file. Extraction uses only verified manifest bytes, creates exclusive mode-0600 files, and does not preserve archive ownership or unsafe modes. A post-extraction audit recursively uses `lstat`, requires `nlink === 1`, rejects links and special types, checks the exact file set, count and byte bounds, sizes, hashes, and effective `realpath` containment. Fixtures are created only after this audit.

The loading check defines one exact physical package root, its exact bundled-core root, one exact root for each controlled peer, the exact TypeScript fixture root, the exact loader file and fixture root, and the exact child script file. The generated loader resolves every non-built-in import with `realpath` before loading or transpiling it. It rejects non-file schemes and files outside the package, bundled-core, peer, or exact child-script allowlist. It writes a bounded import record below the helper root. The parent verifies each record category and physical path after the child exits. It also requires records for the package entries and the resolved bundled core and peers used by the check. A deterministic symlink-escape fixture proves rejection before the external fixture can create its load sentinel. Node does not route loader dependencies through the loader hook, so the test checks the loader and TypeScript implementation separately under their exact fixture roots. The TypeScript fixture uses only the direct package-local development dependency. Its source manifest must resolve below the package-local `node_modules/typescript` root. The reviewed lock record is pinned to version `5.9.3` and integrity `sha512-jl1vZzPDinLr9eUt3J/t7V6FgNEw9QjvBPdysz9KfQDD41fQrC2Y4vKQdiaUpFT4bXlb1RHhLpp8wtm6M5TgSw==`. Before fixture creation, the manifest and `lib/typescript.js` bytes must match their reviewed SHA-256 values. The fixture contains only those two verified files. Copied fixture trees are recursively checked for symlinks. Positive allowlisted physical roots provide the containment proof. These checks prove the reviewed local fixture bytes, not authenticated npm registry provenance.

The test covers umbrella and separate notes/workplan source packs, bundled-core payloads, declared extension order, fabricated state reads, locked loader identity, exact release digest and provenance, clean loading, bounded child output, and deterministic rejection of wrong digests, supplied symlinks, oversized compressed artifacts, gzip CRC and ISIZE errors, gzip flags, empty or incorrectly terminated tar streams, noncanonical numeric fields, reserved bytes, nonempty link and owner names, nonzero device fields, archive links, hard-link headers, FIFO headers, duplicate paths, newline/C0/bidi names, traversal or absolute paths, and pre-populated extraction targets. Each archive case goes through custody and records that extraction, fixture creation, and loading did not start. The fixtures use only Node standard-library archive construction and controlled peer files.

This contract is tested on the current POSIX Node.js 22+ environment and the reviewed npm gzip/strict-ustar format. Unsupported future npm archive extensions fail closed. The test uses fabricated public-safe state only. Live rollback remains a private concern and is not proven by this test.
