# @grounded/pi-files

Full-fidelity `read`, strict atomic `edit`/`write`, and unified `local_search` with explicit text, files, and fuzzy strategies for Pi. See the `pi-grounded-tools` repository README for schemas, artifacts, trial mode, and requirements.

Optional `sessionId` routes a file operation through an existing local or SSH Grounded session. Relative paths use the captured session working directory. The operation shares the session command FIFO. Edit and write keep their canonical path mutation queue inside that FIFO slot. Omission uses the unchanged direct local path.

Local sessions use direct filesystem operations. An SSH session must provide file-resource protocol v1. Grounded Files keeps exact candidate construction, anchors, digests, syntax checks, mutation serialization, search filtering, cursors, and rendering. The provider supplies bounded raw reads, canonical remote identity, digest-checked same-directory commits, and structured exact search inventory. Remote writes report rollback availability and hard-link count. They do not claim hard-link topology preservation or rollback. Remote `pdf_structure`, session fuzzy search, missing resources, unknown sessions, and failed providers all fail closed. No operation creates a session or selects a route implicitly.

This package registers the versioned `pi-grounded-tools/files-v1` Review UI preview adapter. The adapter is bound to this exact extension source path. Edit and write previews use the same pure content-construction functions as execution. Proposed BOM, CRLF, digest, anchored edit, and strict replacement bytes are exact. The currently retained Review UI source is inactive and does not understand session-relative paths, so this adapter rejects session-relative preview requests. Review UI must also fail closed if a different tool owner is active.
