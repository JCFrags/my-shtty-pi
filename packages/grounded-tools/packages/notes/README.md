# @grounded/pi-notes

Explicit session-tree scratchpad notes for Pi.

Notes follows the active branch. It survives compaction and reload through event replay. It does not capture text automatically. It is not memory, trusted facts, or instruction storage.

Do not store passwords, keys, tokens, cookies, private keys, or other secrets in notes.

Large exact reads can create a private temporary output artifact. The tool does not accept a file path and cannot import that artifact.
